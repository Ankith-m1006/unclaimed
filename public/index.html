GitHub lists an issue as open even when it already has a pull request or five people asking for it in the comments. Unclaimed checks assignees and linked PRs, then has Gemma (running on our own server) read each thread, so you only see issues that are really free.

Examples:
0 Free 0 Claimed 0 Has a PR 0 Assigned 0 Not ready Not checked yet

Check a repository

Enter a repo and a label, then press Check issues. The newest matching issues are checked first.
How verdicts are decided. Assigned, has a PR and not ready come straight from GitHub. Claimed and free come from Gemma reading the comments; every claim links to the comment it is based on. Always read the thread yourself before asking for an issue.
